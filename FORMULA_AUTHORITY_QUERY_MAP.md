# MedMaths Formula Authority Query Map

Updated: 30 July 2026

## Purpose

Each calculator page has one clear primary search job and a set of distinct supporting questions. Long-tail phrases stay when they answer a real user need. Competitor-brand comparisons are excluded.

The sitewide explanation order is:

1. Meaning and definition
2. What the calculator does
3. What each input means
4. Formal equation
5. Formula in plain English
6. User-number substitution
7. Step-by-step arithmetic
8. Displayed result and exact result
9. What the result means
10. Formula differences, mistakes and limitations
11. Useful long-tail FAQs
12. Original or authoritative sources

## Rules for long-tail content

- Keep a long-tail heading when its answer adds distinct information.
- Merge headings only when the answer would be materially repetitive.
- Use correct spelling in visible content even when search queries contain misspellings.
- Do not name competing calculator websites to attract their branded traffic.
- Do not claim that one formula is universally best.
- Keep all important formula explanations in server-rendered HTML.
- Use calculator-specific language rather than a copied generic paragraph.
